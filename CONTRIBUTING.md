# Contributing

Thanks for your interest. This is a small personal project, so issues and small pull requests are
the best way to help.

1. Fork and create a branch.
2. `make dev` to install with development dependencies.
3. Make your change with a test. Use synthetic data only; never commit real participant data,
   real keys, passphrases or data files.
4. `make check` must pass (ruff lint and format, mypy, pytest).
5. Open a pull request that says what changed and why.
